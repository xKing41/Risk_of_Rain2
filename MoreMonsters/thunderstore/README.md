# MoreMonsters

## New elite types
Any enemy can spawn as one of these:

| Elite | Effect |
| --- | --- |
| Vampiric | Heals for 40% of the damage it deals |
| Storm | Hits trigger chain lightning |
| Toxic | Hits poison |
| Armored | +100 armor, reflects 10% of damage taken |
| Frenzied | +50% attack speed, +40% movement speed |
| Volatile | Explodes on death |

## New enemies and bosses
| Role | Enemies |
| --- | --- |
| Teleporter bosses | Beetle King, Ancient Golem, Lemurian Patriarch, Void Titan, Clay Colossus |
| Minibosses | Giant Beetle, Hell Imp, Bison Alpha, Mushrum Elder |
| Common enemies | Pebble Golem, Lemurian Hatchling, Imp Scout |

They are variants of existing monsters with their own size, stats, name and role, and spawn on every stage.
Everything can be turned off in the config.
