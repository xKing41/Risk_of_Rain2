# PlayableMonsters

12 new survivors, built from the game's own monsters, with their original models, animations and attacks:

Lemurian, Elder Lemurian, Stone Golem, Beetle, Beetle Guard, Imp, Clay Templar, Bighorn Bison,
Parent, Void Reaver, Lunar Chimera (Golem), Mini Mushrum.

Slots where a monster has no attack of its own get a skill from **MoreSkills**, and every monster
can pick from all MoreSkills skills as well. Stats are balanced to survivor level.
Every survivor can be turned off in the config.
