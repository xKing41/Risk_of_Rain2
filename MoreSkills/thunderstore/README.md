# MoreSkills

Every survivor, including survivors from other mods, gets 16 extra skills in the loadout menu:

| Slot | Skills |
| --- | --- |
| Primary | Arcane Bolt, Chain Lightning, Precision Shot, Scattershot |
| Secondary | Frag Grenade, Missile Volley, Shockwave, Frost Lance |
| Utility | Dash, Blink, Ground Slam, Barrier |
| Special | Thunderstorm, Healing Nova, Berserk, Meteor |

The skills use no custom animations, so they work on any character. Every skill can be turned off in the config.
